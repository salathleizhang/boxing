# hands.glb

作者手部演示使用的原始配套模型，白色手套和前臂，包含独立左右手骨架。

- 来源：https://github.com/bandinopla/three-mediapipe-rig/blob/3ab212719826cb762d08b27cd987dba41d96701c/public/hands.glb
- 仓库：bandinopla/three-mediapipe-rig，版本 0.1.41。
- 文件逐字节复制自本地完整上游快照；应用按左右手选择三角形，并在装配时移除 `arms` 材质对应的黑色胳膊网格，只显示手套。
- 项目代码声明 MIT；上游没有另列配套模型的来源或资产授权。完整原始仓库材料保存在 `vendor/three-mediapipe-rig/upstream/`。

这是界面自带资源，不进入用户资产库或 scene.json。
