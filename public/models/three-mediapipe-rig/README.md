# hands.glb

从用户指定的本地 ChatSpace 项目原样复制的原始配套模型，白色手套和前臂，包含独立左右手骨架。

- 上游来源：https://github.com/bandinopla/three-mediapipe-rig/blob/3ab212719826cb762d08b27cd987dba41d96701c/public/hands.glb
- bandinopla/three-mediapipe-rig，版本 0.1.41。
- 运行时沿用 ChatSpace 的 libraryHandModel 适配，按左右手选择三角形，移除 arms 材质的黑色胳膊网格。
