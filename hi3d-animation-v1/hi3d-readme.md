## 动作

所有角色均为 17 根骨骼、30 fps，包含 4 个独立动画片段：

| 动画名 | Blender 帧范围 | 时长 | 用法 |
| --- | --- | --- | --- |
| `Idle` | 1–61 | 2.0 秒 | 循环待机、防守 |
| `LeftPunch` | 1–34 | 1.1 秒 | 单次左拳，末尾回防守 |
| `RightPunch` | 1–34 | 1.1 秒 | 单次右拳，末尾回防守 |
| `Recoil` | 1–16 | 0.5 秒 | 单次受击，末尾回防守 |

GLB 以秒记录动画时间；米制、Y 轴向上、正面朝 +Z。奶龙高度 1.85 米，其余 1.9 米。所有动作原地播放、脚底固定；拳套使用整掌骨骼。原始约 200 万三角面和 8192 贴图均保留，单个 GLB 约 65 MiB。

可把 `models/` 下需要的文件复制到项目的 `public/models/opponents/`，并令对应角色的 `modelUrl` 指向该文件；动画按上表名称选取。单次动作的播放、混合和触发由项目控制。
